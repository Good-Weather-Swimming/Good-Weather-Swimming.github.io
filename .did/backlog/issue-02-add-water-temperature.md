# Issue 02: Add Water Temperature Data

## Description
The site currently lacks real-time water temperature data, which is essential for swimmers to determine if conditions are suitable. Water temperature significantly impacts swimming comfort and safety.

## Requirements
- Add water temperature field to location data model
- Integrate with Open-Meteo Marine API for sea surface temperature data
- Display water temperature on location pages
- Add filtering for water temperature thresholds (e.g., >18°C)

## Acceptance Criteria
- [ ] Water temperature field added to location data model
- [ ] Water temperature displayed on location pages
- [ ] Filtering option for water temperature threshold
- [ ] Data updated in real-time via Open-Meteo Marine API
- [ ] Clear indication of water temperature on all relevant pages

## Priority
High
