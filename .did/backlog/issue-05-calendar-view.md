# Issue 05: Add Calendar View for Swim Days

## Description
The site needs a dedicated calendar view showing recommended swim days for each location based on weather conditions. The current calendar uses a broken API endpoint and needs replacement.

## Requirements
- Create calendar component for each location
- Generate weekly/monthly calendar of recommended swim days
- Mark days with good weather conditions
- Integrate with Open-Meteo weather data
- Add color coding for weather conditions
- Make calendar responsive on mobile devices

## Acceptance Criteria
- [ ] Calendar component built and deployed
- [ ] Days marked based on weather conditions
- [ ] Integration with Open-Meteo API complete
- [ ] Color coding for weather types implemented
- [ ] Mobile responsive
- [ ] Accessible with proper labels
