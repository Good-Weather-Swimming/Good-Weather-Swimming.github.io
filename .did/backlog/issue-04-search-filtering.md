# Issue 04: Create Search and Filtering Functionality

## Description
Users need the ability to search for swimming locations and filter by various criteria such as weather conditions, amenities, distance, and user ratings. Currently, the site lacks search and filtering capabilities.

## Requirements
- Add search box to home page for location search
- Implement filtering controls:
  - Water temperature threshold (e.g., >18°C)
  - Amenities (toilets, showers, lifeguard presence)
  - Distance from user location
  - User rating (stars)
  - Weather conditions (rain, wind, etc.)
- Enable combined filtering
- Ensure mobile-friendly UI

## Acceptance Criteria
- [ ] Search box added to home page
- [ ] Filter controls implemented
- [ ] Combined filtering functional
- [ ] Results update dynamically
- [ ] Mobile responsive design
- [ ] Integration with weather and location data

## Priority
High
